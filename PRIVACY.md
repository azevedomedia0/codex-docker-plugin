# Privacy policy

Effective date: July 23, 2026

Docker for Codex is a skills-only plugin published by Azevedo Media. The plugin bundles local instructions, references, and helper scripts for container engineering workflows.

## Data processed

The plugin itself does not operate an external service and does not transmit project files, prompts, credentials, container data, or personal information to Azevedo Media.

When a user explicitly asks Codex to run third-party tools or interact with services such as Docker registries, vulnerability scanners, cloud providers, GitHub, Kubernetes clusters, or signing infrastructure, those tools and services process data under their own terms and privacy policies.

## Local files and command output

Bundled helpers inspect user-selected local projects or generate dry-run plans. Some optional workflows can create local artifacts, run containers, access registries, or change infrastructure only when the user explicitly requests and authorizes those actions.

Users are responsible for reviewing commands and avoiding secrets in prompts, logs, generated files, images, and repositories.

## Retention

Azevedo Media does not receive or retain data through this skills-only plugin. Local files and command output remain subject to the user's Codex, operating-system, repository, and third-party service settings.

## Changes

Material changes to this policy will be published in this repository.

## Contact

For privacy questions, open a private security report or maintainer inquiry through the [project repository](https://github.com/azevedomedia0/codex-docker-plugin).
