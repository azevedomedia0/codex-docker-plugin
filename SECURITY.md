# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository. Include the affected file or workflow, reproduction steps, potential impact, and any suggested mitigation.

The maintainers will acknowledge a complete report as soon as practical and coordinate remediation and disclosure.

## Scope

This plugin provides instructions to Codex and does not bundle a Docker daemon, container runtime, registry credential, or remote service. Reports involving unsafe generated container configuration, secret exposure, destructive defaults, or instruction injection are in scope.
